SAFEWAY AI ASSISTANT — PUBLIC DEVELOPMENT GUIDE
================================================

This guide intentionally excludes production credentials, infrastructure names,
account-provisioning procedures, database administration commands, and internal
deployment details.

Requirements
------------
- Python 3.11 or 3.12
- Node.js 20 LTS or later
- Authorized access to the required development services

Backend installation
--------------------
1. Change to the backend directory.
2. Create and activate a Python virtual environment.
3. Install the pinned dependencies from requirements.txt.
4. Copy .env.example to .env.
5. Request approved development values through the project maintainer or the
   organization’s secret-management process.

Frontend installation
---------------------
1. Change to the frontend directory.
2. Install the locked dependencies with npm ci.
3. Copy .env.example to .env.
4. Use only an approved local backend address.

Running locally
---------------
After both environment files have been configured, run `python run_app.py` from
the repository root. The launcher prints the available local addresses.

Security rules
--------------
- Never commit .env files or real credentials.
- Revoke and replace any credential that was ever committed; removing the latest
  copy does not remove it from Git history.
- Never place secrets in screenshots, issues, pull requests, or documentation.
- Use synthetic information for demonstrations and tests.
- Keep account initialization, recovery, and production deployment instructions
  in access-controlled internal documentation.
- Report suspected security problems privately to the project maintainer.
